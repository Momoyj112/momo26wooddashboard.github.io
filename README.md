# 广西大宗木材线上交易平台 - 大屏离线原型

## 运行方式
1. 解压整个项目文件夹。
2. 双击打开 `index.html` 即可运行，无需启动服务、登录或连接后端。
3. 请保持 `assets`、`css`、`js` 文件夹与 `index.html` 的相对位置不变。

## 项目说明
- 技术栈：HTML + CSS + 原生 JavaScript。
- 设计画板：1 个，约 1334 × 960，依据切图包中的 Sketch MeaXure 设计数据和预览图重建。
- 本地资源：复用原始切图包内图片、图标，并从预览图裁取地图与商品缩略图区域。
- 页面适配：按原始画板比例整体缩放，适配不同屏幕尺寸。
- 交互：商品卡片、交易服务数据卡、行情价格卡、底部供应链模式按钮提供本地演示反馈；时间显示自动更新；趋势图、年度成交图及列表由本地模拟数据绘制。

## 当前材料边界
切图包只包含一个大屏画板；`links` 和 `proto.html` 仅跳转回设计查看器，没有额外页面或明确的原型连线。因此项目还原的是这一张大屏，不擅自扩展未提供的业务页面。页面中的示例成交数据沿用预览稿展示内容，属于静态演示数据，不代表实时业务数据。
